# School surface atlas

`school-surfaces-v1.png` was generated with the built-in image generation tool for this project.

Prompt:

> Use case: photorealistic-natural. Asset type: texture atlas for a 3D school game. Generate a square flat-lay photograph of four distinct realistic seamless, evenly lit construction material surfaces arranged as an exact 2 by 2 grid with no borders, no labels, no text, no objects and no perspective. Upper left: pale sage green painted fine exterior plaster, slightly weathered like an old Russian school. Upper right: muted dusty salmon painted fine exterior plaster. Lower left: worn red-brown varnished wooden sports hall floorboards with subtle grain and seams, viewed directly from above. Lower right: fine gray asphalt with small aggregate and gentle natural wear. Each quadrant must contain only its surface, uniform color, no heavy shadows, tileable in all directions. Natural photographic texture, not illustration.

# Богатыри — Земля русская

Браузерная 3D-арена на Next.js, React и Three.js. Илья Муромец, Добрыня Никитич и Алёша Попович с разными характеристиками, оружием и особыми способностями. Три цветовых варианта доспехов для каждого богатыря, интерактивный просмотр моделей и авторские иллюстрации. Большой исследуемый мир с деревнями, кузницами, часовнями, мельницами, лесами и сторожевыми площадками с лестницами.

## Запуск

```sh
npm install
npm run dev
```

Откройте адрес Local, напечатанный Next.js. Если порт 3000 занят, Next.js выберет следующий свободный порт.

## Играть с друзьями

1. Запустите один сервер и откройте игру.
2. Выберите богатыря, облик и «Создать дружину».
3. В бою нажмите «Пригласить» и отправьте ссылку друзьям. Ссылка открывает вход в комнату; также можно выбрать «Присоединиться» в лобби и ввести шестизначный код.
4. До трёх игроков могут сражаться одновременно. Мир работает без ограничения по времени и числу побед. Все игроки возрождаются в одном лагере через три секунды и получают короткую защиту. Лагерь — мирная зона: там нельзя атаковать, а боты уходят в окрестности.

В одной локальной сети используйте адрес Network из вывода Next.js на всех устройствах. `localhost` на компьютере друга обозначает его собственный компьютер. Для доступа через интернет нужен доступный извне Node.js-сервер.

Тренировка создаёт отдельную арену с двумя ботами. Подключиться к ней другим игрокам нельзя.

## Управление

Нажмите на игровое поле, чтобы захватить мышь. При прицеливании из лука удерживайте ЛКМ или J для натяжения и отпустите для выстрела: полное натяжение усиливает урон; цифры над героями показывают полученный урон. Вращение камеры свободное по горизонтали и вертикали, колёсико меняет расстояние. WASD двигает героя относительно камеры. Esc освобождает курсор и открывает меню; I или Tab открывает и закрывает инвентарь. Если браузер не поддерживает захват мыши, вращайте камеру, удерживая ПКМ; блок остаётся на F.

| Действие | Клавиши |
|---|---|
| Движение | WASD / стрелки |
| Камера | Мышь, колёсико — расстояние |
| Прыжок | Пробел |
| Бег | Удерживать Shift |
| Перекат | Ctrl |
| Атака / выстрел | ЛКМ или J, можно удерживать |
| Прицел из лука | Удерживать ПКМ или C, затем удержать ЛКМ или J и отпустить для выстрела |
| Блок щитом | ПКМ или F; во встроенном предпросмотре — F |
| Особая способность | Q, перезарядка 8 секунд |
| Инвентарь | I / Tab |
| Булава / меч / лук | 1 / 2 / 3 |
| Целебный настой / хлеб | 4 / 5 |
| Подобрать припасы | E рядом с предметом или ресурсом |
| Меню и освобождение курсора | Esc |

В суме есть три вида оружия, стрелы, настои (+55 здоровья) и хлеб (+60 выносливости). По большому миру раскиданы редкие руда, древесина и кристаллы. Во вкладке «Крафт» сумы нажмите на рецепт, чтобы заполнить сетку 3×3, или разложите материалы вручную. Рецепты без необходимых ресурсов затемнены и недоступны для выбора. Сначала создайте слитки и доски из сырья, затем разложите материалы по показанному рецепту: выберите ресурс и нажмите на ячейку или перетащите его мышью. Без верстака создаются улучшенные меч, булава, лук, сапоги (+20% скорости) и доспех (−25% урона). За сбор ресурсов, создание предметов и победы начисляется опыт. Каждый уровень даёт очко, которое в суме можно вложить в силу, здоровье или скорость; некоторые рецепты открываются на 2–3 уровне. Ресурсы, уровни и улучшения сохраняются после гибели в текущей комнате; ресурсы возвращаются на карту через 90 секунд. Выстрел расходует стрелу; атаки, прыжок, бег и перекат тратят выносливость. Припасы общие для комнаты и появляются снова через 18 секунд после подбора.

Физика учитывает стены, деревья, бочки, ящики, воду, навесы и других игроков. По лестницам можно подняться на площадки сторожевых построек. Можно перепрыгнуть низкую стену или приземлиться на ящик; мост приподнят над водой. Атаки не проходят через здания. В 3D анимированы ходьба, бег, прыжки, блок, перекаты, три вида атак, специальные приёмы, получение урона, использование предметов и падения. Неподвижные части моделей объединяются по материалам без уменьшения числа полигонов.

На сенсорном экране доступны кнопки движения и действий; проведите пальцем по свободной части игрового поля, чтобы повернуть камеру. Настройки имени, звука, героя и облика сохраняются в браузере. В лобби откройте «Снаряжение и магазин»: у каждого богатыря свои головные уборы и щиты, некоторые доступны после получения уровня. За сбор ресурсов, создание вещей и победы начисляются монеты. Монеты, покупки и максимальный уровень каждого героя сохраняются в этом браузере; они влияют только на внешний вид.

## Проверки

```sh
npm test
npm run typecheck
npm run build
```

Тесты проверяют комнаты, приватность, вместимость, движение, границы карты, столкновения с объектами и игроками, прыжки, приземление, потолки, мост, воду, атаки и направление щита, препятствия для выстрелов, уклонение, оружие, боезапас, способности, расходники, подбор припасов, возрождение, крафт и точное прицеливание. Проверки используют управляемые часы и не требуют запущенного HTTP-сервера.

## Архитектура и ограничения

- `lib/scene.ts`: плавные модели, суставы, три вида оружия, материалы и анимации.
- `lib/world.ts`: единое описание объектов, препятствий, припасов и физика для сервера и клиента.
- `lib/map-scene.ts`: визуальное окружение посада, собранное по общему описанию.
- `lib/game-client.ts`: захват мыши, камера с защитой от препятствий, локальное предсказание движения, эффекты и рендеринг.
- `components/arena.tsx`: Three.js, ввод, интерполяция состояний других игроков, эффекты, звук и HUD.
- `lib/arena-server.ts`: сервер рассчитывает движение, попадания, урон, способности, счёт и возрождение. Клиенты передают только ввод, а не здоровье или координаты.
- `app/api/arena/route.ts`: подключение и обмен состоянием через HTTP примерно 20 раз в секунду; одновременные запросы от одного клиента не перекрываются.
- Комнаты, ресурсы, уровни и крафт хранятся в памяти **одного процесса Node.js**: после смерти сохраняются, при выходе из комнаты или перезапуске сервера сбрасываются. Для нескольких серверов и постоянного хранения потребуется общее хранилище. Отключившийся игрок освобождает место через 30 секунд.
- Это игровой прототип: иллюстрации меню и процедурные 3D-модели — разные виды графики. Модели не являются сканами или фотореалистичными персонажами уровня AAA.

Авторская графика и использованные запросы: [public/art/README.md](public/art/README.md).
